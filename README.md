# 🚗 ChalakSetu — Intelligent Mechanic Finder System

ChalakSetu is a location-based intelligent mechanic finder web application that helps users quickly find nearby mechanics during vehicle breakdown situations.

This system is designed with a clean architecture, secure authentication using Email OTP, and a user-friendly interface suitable for real-world deployment and academic/patent presentation.

---

## 🚀 Key Features

- 📍 Location-based mechanic discovery
- 🔐 Secure Signup & Login with Email OTP
- 🔁 Forgot Password with Email OTP verification
- 🧭 Interactive UI with smooth animations
- 🗂️ Clean and self-written Flask backend structure
- 🛡️ Security-focused design (hashed passwords, session control)

---

## 🛠️ Tech Stack

- Python (Flask)
- HTML, CSS, JavaScript
- SQLite / Database
- Email OTP Authentication
- Render Deployment
